## What I Did

- Led Strapi CMS architecture across content models, admin plugins, integrations, and deployment support.
- Built and maintained Strapi CMS content models for public pages, marketplace content, events, partners, teams, media, SEO, sitemap, and request-introduction flows.
- Implemented custom Strapi admin plugin screens using React, Strapi Design System, hooks, tables, dialogs, search, filters, pagination, sorting, and loading/empty states.
- Integrated opportunity review workflows with Coaxis APIs for listing, status changes, preview/view links, reviewer tokens, opportunity settings, and collaborator management.
- Built AI/II verification admin workflows for fetching verification records and approving or rejecting records through backend service wrappers.
- Supported production deployment and operations through Cloud Build, App Engine, Cloud Storage uploads, database configuration, Artifact Registry auth, and managed secret wiring.
- Added support endpoints for external admin auth, SendGrid template lookup, and CMS configuration maintenance.

## Impact Framing
