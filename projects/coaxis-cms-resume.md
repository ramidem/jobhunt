# Coaxis CMS Resume Companion

## Purpose

Turn the Coaxis CMS source review into concise resume material for backend, full-stack, CMS/platform, and product-engineering roles.

## Best Resume Positioning

Position this as Symph client work, not a hobby project. The strongest angle is a Strapi/TypeScript CMS platform with custom admin plugins that connected internal CMS operators to Coaxis opportunity, verification, and content workflows.

Best fit:

- Backend / full-stack roles needing CMS, admin tooling, and API integration
- Product engineering roles involving internal operations workflows
- Platform roles involving deployment, cloud configuration, and content systems

Avoid overemphasizing generic content editing. The stronger signal is custom Strapi plugin work, admin workflow implementation, API integration, and deployment support.

## What I Did

- Built and maintained Strapi CMS content models for public pages, marketplace content, events, partners, teams, media, SEO, sitemap, and request-introduction flows.
- Implemented custom Strapi admin plugin screens using React, Strapi Design System, hooks, tables, dialogs, search, filters, pagination, sorting, and loading/empty states.
- Integrated opportunity review workflows with Coaxis APIs for listing, status changes, preview/view links, reviewer tokens, opportunity settings, and collaborator management.
- Built AI/II verification admin workflows for fetching verification records and approving or rejecting records through backend service wrappers.
- Supported production deployment and operations through Cloud Build, App Engine, Cloud Storage uploads, database configuration, Artifact Registry auth, and managed secret wiring.
- Added support endpoints for external admin auth, SendGrid template lookup, and CMS configuration maintenance.

## Impact Framing

- Helped turn Strapi from a basic content store into an operational CMS for opportunity review and verification workflows.
- Reduced manual admin friction by bringing review actions, collaborator management, preview links, and opportunity settings into the CMS admin.
- Improved reliability of CMS operations by moving Coaxis API calls behind Strapi services and typed admin hooks.
- Supported production readiness through GCP deployment configuration, environment handling, cloud storage, and database setup.

No numeric impact was confirmed from source. Do not invent metrics.
